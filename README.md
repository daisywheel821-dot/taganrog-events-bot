# Taganrog Events Bot 🤖

Telegram бот, который каждый день в 9:00 отправляет события Таганрога в готовом формате для постов в соцсетях (MAX).

## Что это?

Парсит события из Яндекс Афиши и 2GIS, форматирует как готовые посты и отправляет в Telegram. Экономит время на поиск и оформление событий.

## Как работает?

```
9:00 каждый день
    ↓
Бот парсит события Таганрога
    ↓
Форматирует как пост для MAX
    ↓
Отправляет в твой Telegram (@M0Honey)
    ↓
Копируешь → публикуешь в канал
```

## Установка на Railway (5 минут)

### 1. Получить Telegram токен

- Напиши боту `@BotFather` → `/start` → `/newbot`
- Назови бота (например: `Taganrog Events Bot`)
- Придумай username (например: `taganrog_events_bot`)
- Получишь токен вида: `123456:ABCdef...`
- **Скопируй этот токен!**

### 2. Получить свой Chat ID

- Напиши боту `@userinfobot` → `/start`
- Получишь свой Chat ID (число вроде `123456789`)
- **Скопируй Chat ID!**

### 3. Развернуть на Railway

1. Регистрируешься на https://railway.app (GitHub быстрее)
2. Нажимаешь **"New Project"** → **"Deploy from GitHub"**
3. Выбираешь этот репозиторий (`taganrog-events-bot`)
4. Railway автоматически найдёт файлы и начнёт развёртывание
5. Добавляешь переменные окружения в **"Variables"**:
   ```
   TELEGRAM_TOKEN = (вставь токен от BotFather)
   CHAT_ID = (вставь свой Chat ID)
   ```
6. Нажимаешь **"Deploy"**

### 4. Готово!

В 9:00 каждый день бот отправляет события в твой Telegram. Копируешь текст → публикуешь в MAX.

## Редактировать время отправки

Если хочешь другое время вместо 9:00:

1. Открываешь файл `taganrog_events_bot.py`
2. Ищешь строку: `hour=9`
3. Меняешь цифру:
   - `hour=8` = 8:00
   - `hour=10` = 10:00
   - `hour=19` = 19:00
4. Загружаешь обновлённый файл на GitHub
5. Railway автоматически перезагружается

---

## Редактировать формат сообщений

1. Открываешь `taganrog_events_bot.py`
2. Ищешь функцию `format_event_for_max()`
3. Меняешь текст шаблона
4. Загружаешь на GitHub → Railway перезагружается

## Если что-то не работает

| Проблема | Решение |
|----------|---------|
| Бот не отправляет сообщения | Проверь TELEGRAM_TOKEN и CHAT_ID в Railway |
| Отправляет не в 9:00 | Проверь часовой пояс (Europe/Moscow) |
| "ModuleNotFoundError" | Убедись что requirements.txt на месте |
| Бот перестал работать | Перезагрузи приложение (кнопка "Restart" в Railway) |
